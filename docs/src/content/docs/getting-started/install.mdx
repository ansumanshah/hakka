<Aside type="tip" title="Fastest path">
Run the setup CLI — it detects your framework (Next.js, Vite, Expo, React Native, or plain web) and wires Hakka up for you. Dependency-free and idempotent.

```bash title="Terminal"
npx hakka-cli init
```

</Aside>

## Install commands

The npm packages, if you'd rather wire them up by hand. Follow the platform page for the full setup. The coordinated
0.1.1 release is still being prepared; check [GitHub Releases](https://github.com/ansumanshah/hakka/releases) for
published artifacts.

<Tabs syncKey="pkg-manager">
  <TabItem label="npm">

```bash
npm install hakka-react-native   # React Native / Expo
npm install hakka-browser            # Web
npm install hakka-node hakka-browser # Next.js
npm install hakka-cli            # CLI setup, diagnostics, MCP, and CDP
```

  </TabItem>
  <TabItem label="pnpm">

```bash
pnpm add hakka-react-native   # React Native / Expo
pnpm add hakka-browser            # Web
pnpm add hakka-node hakka-browser # Next.js
pnpm add hakka-cli            # CLI setup, diagnostics, MCP, and CDP
```

  </TabItem>
  <TabItem label="yarn">

```bash
yarn add hakka-react-native   # React Native / Expo
yarn add hakka-browser            # Web
yarn add hakka-node hakka-browser # Next.js
yarn add hakka-cli            # CLI setup, diagnostics, MCP, and CDP
```

  </TabItem>
  <TabItem label="bun">

```bash
bun add hakka-react-native   # React Native / Expo
bun add hakka-browser            # Web
bun add hakka-node hakka-browser # Next.js
bun add hakka-cli            # CLI setup, diagnostics, MCP, and CDP
```

  </TabItem>
</Tabs>

For a separate local hub, run `npx hakka-bridge`; `hakka-node`, the browser overlay, and the CLI can also host or
connect to the same local bridge. See the [bridge guide](/bridge/overview/) for the connection options.

Native SDKs install through their own package managers — see [Android](/android/sdk/) (Maven) and [iOS](/ios/sdk/) (Swift Package Manager).

<Aside type="tip" title="Local-first, always">
  Hakka has no default cloud upload. Captures stay local unless you explicitly export them or connect a bridge or sink.
</Aside>
